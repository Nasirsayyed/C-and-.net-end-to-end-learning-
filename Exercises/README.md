# Exercises

Every module's `README.md` ends with a **🧪 Practice Exercises** section: 5 Easy, 5 Medium, 5 Hard, and 1 Real-World Scenario. This directory doesn't duplicate them — it indexes them and gives guidance on how to actually use them.

## How to practice effectively
1. **Do exercises without looking at the module's example code first** — attempt from the concept explanation alone, then compare your solution against the module's examples.
2. **Don't skip the Real-World Scenario** — it's deliberately the least well-specified exercise, forcing you to make judgment calls the way a real task would, not follow a spec.
3. **Redo Easy exercises from earlier modules using later concepts** — e.g. after learning [14 — Modern C#](../14-Modern-CSharp), go back and rewrite [02](../02-Data-Types)'s exercises using records and pattern matching.

## Suggested cadence
- **1-2 modules per week** if working through this alongside a job, doing all Easy + Medium exercises and at least 2 Hard ones per module.
- Keep a personal solutions repo (or a `solutions/` folder alongside this one, gitignored from the main learning repo if you fork it) — comparing your solution to itself a few months later is one of the best ways to see your own growth.
